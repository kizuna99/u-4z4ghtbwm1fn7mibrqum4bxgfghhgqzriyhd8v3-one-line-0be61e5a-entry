A single self-contained one-liner, written by `main.ts` to `/output/entry.txt`:

> My smart fridge judged my midnight snack so hard it emailed my doctor a witness statement.

## Why this line

Picked by a head-to-head tournament against the published judge criteria, in order:
self-contained funny line first, then a real laugh (a double escalation — judged,
emailed, *witness statement*), tightness, freshness (no known-joke template), and
clarity on first read.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts   # or any TS runner / ts-node
cat /output/entry.txt
```
